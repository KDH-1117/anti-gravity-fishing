# 🎣 안티그래비티 축제 낚시 부스 웹 애플리케이션
> **1학년 5반 축제 전용 실시간 다중 기기 연동 낚시터 시스템**  
> **배포 스택**: Vercel (웹 호스팅 & 프론트엔드) + Supabase (실시간 PostgreSQL 클라우드 DB)

---

## 🌟 시스템 구성 및 역할 분담 (최소 4대 이상 기기 운용)

본 시스템은 축제 현장에서 별도의 복잡한 백엔드 서버(Render 등) 없이, **Vercel + Supabase Realtime**만으로 모든 기기가 0.1초 만에 실시간 동기화되도록 설계되었습니다.

```
[운영진 태블릿/스마트폰] (1~3대)     [부스 전광판/빔프로젝터] (1대)      [총괄 관리자 스마트폰] (1대)
       / (메인 게임)                     /scores (실시간 순위표)                /admin (확률 조작)
             │                                   ▲                                  ▲
             ▼                                   │                                  │
      참가자 점수 입력 ─────────────────────► Supabase Realtime ◄───────────── 실시간 확률/타이머 반영
```

1. **대형 화면 / 빔프로젝터 / TV (`/scores`)**:
   - 실시간 1위~3위(금/은/동 하이라이트 + 왕관 아이콘) 및 전체 랭킹 자동 갱신.
   - 새 점수가 등록될 때마다 새로고침 없이 즉시 애니메이션으로 순위가 업데이트됩니다.

2. **부스 운영진 기기 2~4대 (`/`)**:
   - 닉네임 입력 ➡️ 학번/이름 입력 ➡️ 낚싯대 강화 (Lv.1~Lv.5) ➡️ 타이머 카운트다운 낚시 ➡️ 운영진 수동 점수 입력 ➡️ 완료.

3. **부스 총괄 관리자 기기 (`/admin`)**:
   - **타이머 시간 변경** (30초, 45초, 60초, 90초 등 실시간 변경).
   - **강화 비용 표시 변경** ('1 ESTA', '500원', '1 코인' 등).
   - **확률 조작 시스템 (핵심)**:
     - **시각적 확률**: 참가자 화면에 표시되는 명목상 성공/유지/하락 확률.
     - **실제(Hidden) 확률**: 참가자에게는 숨겨진 채 실제 알고리즘에서 돌아가는 진짜 성공/유지/하락 확률.
     - 원클릭 프리셋: 정직 모드, 축제 대박 모드, 사장님 극악 모드, **희망고문 모드 (추천!)**.
   - **참가자 학번/이름 대외비 명부 조회 및 엑셀(CSV) 다운로드**.
   - **전체 점수 초기화**.

## 🚀 3분 초고속 배포 가이드

### 1단계: Supabase 데이터베이스 생성 (1분)
1. [supabase.com](https://supabase.com)에 무료 가입 후 **[New Project]** 생성.
2. 좌측 메뉴의 **[SQL Editor]** 클릭 ➡️ **[New query]** 클릭.
3. 프로젝트 내 `supabase_schema.sql` 파일의 내용을 그대로 복사하여 붙여넣고 **[RUN]** 클릭.
4. 좌측 **[Project Settings]** (톱니바퀴) ➡️ **[API]** 메뉴에서 다음 2가지 값을 확인:
   - `Project URL` (예: `https://xyzcompany.supabase.co`)
   - `Project API keys`의 `anon` `public` 키

---

### 2단계: Vercel 배포 (1분)
1. GitHub에 현재 프로젝트 코드를 Push합니다.
2. [vercel.com](https://vercel.com) 로그인 후 **[Add New...]** ➡️ **[Project]** 클릭.
3. 해당 GitHub 저장소를 선택(Import)합니다.
4. **Environment Variables** (환경 변수) 섹션을 열고 다음 2개를 입력합니다:
   - `VITE_SUPABASE_URL`: (Supabase Project URL)
   - `VITE_SUPABASE_ANON_KEY`: (Supabase Anon Key)
5. **[Deploy]** 버튼 클릭 ➡️ 약 30초 후 배포 완료!
   - 생성된 URL (예: `1-5-fish.vercel.app`)로 즉시 접속 가능합니다.

---

### 3단계: 축제 현장 기기 접속
- **공통 초기 비밀번호**: `105fish`
- 한 번 올바르게 입력하면 `localStorage`에 자동 보관되어 브라우저를 닫을 때까지 다시 묻지 않습니다.
- 비밀번호는 `/admin` 페이지에서 언제든지 즉시 변경할 수 있습니다.

## 💻 로컬(내 컴퓨터)에서 즉시 실행하는 법

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행 (자동으로 브라우저 열림)
npm run dev

# 프로덕션 빌드 테스트
npm run build
```

*(참고: Supabase를 아직 연결하지 않은 상태에서도 `localStorage` + `BroadcastChannel` 기반으로 같은 브라우저 내 다중 탭 간 실시간 연동이 100% 정상 작동합니다)*
